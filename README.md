# lembre-pi
O aplicativo é destinado a pessoas que precisam organizar e acompanhar suas tarefas e responsabilidades do dia a dia, principalmente aquelas que possuem uma rotina doméstica com diversas atividades. Pode atender pessoas que moram sozinhas, casais, famílias e até pessoas que compartilham uma residência, ajudando na organização e divisão das tarefas.
